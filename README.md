# The Uncertain Oracle


## Short Description
An interactive digital answer book that uses hand gesture tracking to trigger floating tarot-like cards and generate ambiguous responses. This project reimagines the traditional “Book of Answers” as a spatial and embodied interaction.

Interactive Links: https://the-uncertain-oracle-uep8.onrender.com/

## Concept
This project explores how people seek certainty within uncertainty.

Inspired by tarot systems and answer books, it creates a ritual-like interaction where users ask a question and receive a response. However, instead of providing clear answers, the system generates poetic and open-ended phrases.

By replacing conventional input (such as clicking) with hand gestures, the interaction becomes bodily and intuitive. The user does not control the system directly, but participates in a process of interpretation, where meaning is constructed rather than given.


## Features
**Gesture-based interaction** using MediaPipe hand tracking

**Real-time card shuffling** driven by palm velocity data

**Fist detection mechanic** to trigger selection

**Visual gesture trail** that records hand movement over time

**Randomised answer generation** from a JSON dataset

**Atmospheric background** sound triggered on user interaction

**Reset system (R key)** to restart the ritual


## Technologies Used
p5.js (visual rendering)

MediaPipe (hand tracking)

JavaScript (interaction logic)

JSON (answer database)


## How to Run
**How users interact with the system.**

1.Open the webpage and allow camera access

2.Stand in front of the screen so your hand is visible to the camera

3.Think of a question in your mind

4.Move your hand to interact with the floating cards

5.Wait for the system to generate a response

6.Press R to reset and ask a new question
